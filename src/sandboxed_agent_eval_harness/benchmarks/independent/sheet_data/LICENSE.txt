Changes by Sandbox: selected independently usable offline cell-formula
problems, projected source workbooks to visible input values and date/time
formats, removed metadata, links and macros, added formula-edit instructions,
regrouped the public problem IDs, and added scorer-only reference formulas
and a tested incorrect edit. The source archive, question ID, and SHA-256
hashes of the original input and golden workbook accompany each task.
The scorer also verifies the same formulas on a second, independently supplied
workbook with different expected target values. Both workbooks represent one
original forum problem. The gold files and source
questions are already publicly released upstream. The split controls reuse
in this local study; it makes no claim about prior model training exposure.
